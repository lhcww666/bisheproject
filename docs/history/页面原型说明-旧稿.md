# 页面原型说明

## 一、页面范围

第一期仅完成以下页面，即可演示完整的“学生预约 -> 教师审核 -> 学生查看结果”流程。

| 端 | 页面 | 必要内容 | 对应接口方向 |
| --- | --- | --- | --- |
| 公共 | 登录页 | 用户名、密码、登录按钮 | `POST /auth/login` |
| 学生 | 工作台 | 有效预约、安全考试、信用分、近期预约 | `GET /dashboard/student` |
| 学生 | 实验室列表 | 条件筛选、空闲时间、容量、安全等级、设备概览 | `GET /labs` |
| 学生 | 预约申请页 | 实验室、时间、实验名称、人数、设备、说明 | `POST /reservations` |
| 学生 | 我的预约 | 预约状态、审核意见、取消操作 | `GET /reservations/mine` |
| 学生 | 安全考试 | 考试入口、答题、成绩和有效期 | `/safety-exams/*` |
| 教师 | 审核工作台 | 待审核列表、学生资质、通过/驳回和意见 | `/reservation-reviews/*` |
| 管理员 | 实验室管理 | 实验室新增、编辑、停用 | `/admin/labs/*` |
| 管理员 | 设备管理 | 设备所属实验室、状态和培训要求 | `/admin/devices/*` |
| 管理员 | 安全/信用管理 | 题库、考试记录、信用流水 | `/admin/safety/*`、`/admin/credits/*` |

第二期再增加耗材领用、实验签到、违规记录、统计分析和 AI 聊天记录管理。

## 二、关键交互

### 学生预约

1. 学生在实验室列表中筛选日期、时间和设备。
2. 选择实验室后进入预约申请页，填写实验名称、人数、设备和备注。
3. 后端实时检查时间冲突、实验室容量、安全考试有效期、信用分和高风险审核规则。
4. 符合条件则创建 `PENDING` 或直接创建 `APPROVED` 预约；需要审核时进入教师工作台。
5. 学生在“我的预约”查看结果、审核意见或按规则取消。

### AI 智能预约

AI 页面不能绕过上述预约页面和规则。它先将自然语言整理成预约草稿，展示实验室、时间、人数、设备和资格校验结果；用户点击确认后，才调用与常规预约相同的后端创建接口。

## 三、菜单建议

学生菜单：工作台、实验室资源、我的预约、安全中心、智能助手、个人中心。

教师菜单：工作台、预约审核、实验室日程、学生资质、个人中心。

管理员菜单：工作台、实验室管理、设备管理、预约管理、安全考试、信用分与违规、统计分析、知识库管理、系统管理。

## 四、原型使用说明

交互式原型展示了学生端、教师审核端、管理员端和智能助手四个核心界面。先以该原型确定导航、字段和流程，再使用 Vue 3 + Element Plus 实现页面；原型不代表最终视觉稿，后续以业务功能和可用性为优先。
