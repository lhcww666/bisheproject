# 若依基础项目选型

## 推荐组合

### 前端

[undsky/RuoYi-SpringBoot3-ElementPlus](https://github.com/undsky/RuoYi-SpringBoot3-ElementPlus)

- Vue 3 + Element Plus + Vite
- 仓库 README 标注版本为 v3.9.1
- 适合直接承载学生端、教师端和管理员端页面

### 后端

[undsky/RuoYi-SpringBoot3-Pro](https://github.com/undsky/RuoYi-SpringBoot3-Pro)

- Spring Boot 3 后端版本
- 目录包含 `ruoyi-admin`、`ruoyi-biz`、`ruoyi-framework`、`ruoyi-system` 和 `sql`
- 推荐把实验室业务放在 `ruoyi-biz` 中，避免修改若依底层权限代码

## 为什么选它

你的旧版若依大概率是 Vue 2 + Spring Boot 2 + JDK 8。它虽然可以完成普通管理系统，但后续接 Spring AI 时版本升级工作较多。上面这组项目已经将前端、后端升级到更接近本课题的技术组合，适合从基础框架开始扩展。

`dromara/RuoYi-Vue-Plus` 也比较成熟，但它面向分布式集群，模块和配置更多，学习成本更高。本科毕业设计不需要一开始使用微服务，因此暂不推荐。

## 复用边界

直接复用：登录、JWT、用户、角色、菜单、接口权限、异常处理、日志、代码生成器和基础布局。

自行开发：实验室、设备、预约、审核、安全考试、信用分、签到、耗材和 AI 助手业务。

不要直接复制：与本项目无关的演示模块、复杂租户模块、支付模块和微服务部署配置。

## 开始前检查

1. 下载前后端两个仓库，并确认 README 中的 JDK、Node、MySQL 和 Maven 版本要求。
2. 用 JDK 21 打开后端项目，先不改业务代码，确保原始若依能启动。
3. 启动前端并确认能登录、能进入系统首页。
4. 导入项目自带 SQL，确认若依原有用户、角色和菜单正常。
5. 再导入本项目的 [核心数据库脚本](/D:/bishe_project/sql/lab_ai_platform_core.sql)。如果复用若依用户表，应将实验室表中的用户外键改为若依现有用户表，不要同时维护两套用户账号。

## 关于权限认证

不需要自己从零实现 JWT。复用若依现有认证和权限体系即可。实验室模块只需要在若依菜单中新增实验室、设备、预约、审核、安全考试等权限标识，并在 Controller/Service 上增加对应权限注解。AI 工具调用也必须从当前登录用户上下文取得用户身份，不能让模型传入或伪造用户 ID。
