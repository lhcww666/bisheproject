# 项目命名规范（最终版）

当前统一采用以下命名，不再使用 `lab_`、`LabRoom` 或 `com.ruoyi.lab`：

## 后端

```text
com.ruoyi.module.room
com.ruoyi.module.device
com.ruoyi.module.reservation
```

```text
ruoyi-biz/src/main/java/com/ruoyi/module
├── room
├── device
├── reservation
├── review
├── safety
└── credit
```

类名使用 `Room`、`Device`、`Reservation`，例如 `com.ruoyi.module.room.domain.Room`。

## 前端

```text
ui/src/api/module/room.js
ui/src/api/module/device.js
ui/src/api/module/reservation.js

ui/src/views/module/room
ui/src/views/module/device
ui/src/views/module/reservation
```

## 数据库

```text
room
device
reservation
reservation_device
reservation_review
safety_exam_record
credit_record
```

字段使用 `room_code`、`room_name`、`device_name`、`start_time`、`end_time`，不重复增加 `lab_` 前缀。

代码生成器配置示例：

```text
表名：room
模块名：module
业务名：room
类名：Room
包路径：com.ruoyi.module
```

注意：此前生成的旧 SQL 和旧说明文件仍属于历史参考，正式建表时必须使用按本规范重新生成的 SQL，不能将旧版 `lab_*` 表与新版表混用。
