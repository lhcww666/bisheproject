## 历史文档

[docs/history](history/README.md) 保存早期设计与原型。历史文档可能使用 `lab_room`、`com.ruoyi.lab`、`/lab/...` 等旧口径，只用于追溯设计过程，不作为当前开发和交付依据。

## 文档维护规则

1. 当前实现以代码、`sql/module_core.sql`、`sql/module/` 和 `sql/release/01-bishe_schema_full.sql` 为准。
2. 接口变更后同步更新 `03-接口设计说明书.md`。
3. 表结构变更后同步更新 `10-数据库设计说明书.md` 和对应 SQL。
4. 页面或菜单变更后同步更新 `11-页面与菜单说明.md`。
5. 旧方案需要保留时移动到 `docs/history/`，不得继续放在当前文档目录造成口径混淆。
