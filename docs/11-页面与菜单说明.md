# 校园实验室智能预约与安全管理平台页面与菜单说明

## 1. 页面组织

- 前端目录：`ui/src/views/module`
- API 目录：`ui/src/api/module`
- 路由：由后端 `sys_menu` 动态生成
- 权限：页面按钮和后端接口共同校验

菜单 SQL 位于 `sql/module/`，完整导入后无需手工配置前端路由。

## 2. 角色首页

| 角色 | 首页重点 |
| --- | --- |
| 学生 | 本人预约、信用分、安全考试和近期状态 |
| 教师 | 负责班级待审核预约、学生资质和资源概况 |
| 管理员 | 全校预约、审核、资源使用、安全和耗材统计 |

数据看板由 `/module/stats/dashboard` 提供，前端使用 ECharts 渲染。

## 3. 学生菜单

| 菜单 | 页面 | 作用 |
| --- | --- | --- |
| 预约申请/我的预约 | `reservation/list` | 提交预约、查看状态、签到、结束或取消 |
| 安全考试 | `safetyExam/index` | 查看状态、开始考试和提交试卷 |
| 安全考试记录 | `safetyExamRecord/list` | 查看本人考试结果 |
| 信用分流水 | `creditRecord/list` | 查看本人信用变化 |
| 违规记录 | `violationRecord/list` | 查看本人违规说明 |
| 耗材领用 | `material/apply` | 基于本人预约申请耗材 |
| 智能助手 | `agent/index` | 查询、问答、知识检索和预约草稿 |

学生默认不显示实验室档案和设备档案管理菜单，预约表单通过专用选项接口获取可预约资源。

## 4. 教师菜单

| 菜单 | 页面 | 作用 |
| --- | --- | --- |
| 预约审核 | `reservationReview/list` 或预约详情 | 查看待审核预约、学生资质和审核历史 |
| 实验室档案 | `room/list` | 只读查看授权范围资源 |
| 设备档案 | `device/list` | 只读查看设备 |
| 安全考试记录 | `safetyExamRecord/list` | 查看班级学生考试 |
| 信用分/违规记录 | 对应列表页 | 查看班级学生信用和违规 |
| 智能助手 | `agent/index` | 查询待审核预约和审核依据 |

教师只能在数据范围内查看负责班级学生，审核结果必须在审核页面确认。

## 7. 智能助手页面

Agent 页面由以下部分组成：

- 左侧会话栏：新建、切换和删除会话。
- 中间消息区：历史消息、流式回复、工具调用摘要和草稿卡片。
- 顶部角色卡：显示当前角色助手、知识库入口、模型状态和主题选择。
- 知识库弹窗：不调用模型即可测试 RAG 召回。
- 管理员配置区：模型连接测试和本地 Key 填写说明。

页面提供清爽实验室、奶油糖果和薄荷实验室三种主题，主题只影响显示。

## 8. 菜单与权限维护

新增页面或按钮时必须同时完成：

1. 新增前端页面和 API。
2. 后端增加对应接口和 `@PreAuthorize`。
3. 添加 `sys_menu` 菜单或 `F` 类型按钮。
4. 给相应角色增加 `sys_role_menu`。
5. 重新登录验证动态路由和按钮显示。

菜单脚本位于 `sql/module/`，完整初始化文件 `sql/release/01-bishe_schema_full.sql` 已包含当前全部菜单和角色授权。
