# 本地开发指导书

## 1. 环境要求

- JDK 17 或 JDK 21，当前建议使用 `D:\JDK\jdk-21.0.9`
- Maven 3.6 或更高版本
- Node.js 20 或更高版本，当前使用 Node 22
- MySQL 8
- Redis 3.x 或更高版本
- IntelliJ IDEA、Git

## 2. 目录说明

```text
D:\bishe_project
├── api       Spring Boot 3 后端
├── ui        Vue 3 前端
├── docs      需求、设计和开发文档
└── sql       数据库脚本
```

## 3. 数据库配置

后端配置文件：`api/ruoyi-admin/src/main/resources/application.yml`。

当前开发环境应为：

```yaml
spring:
  profiles:
    active: devmy
```

MySQL 配置文件：`api/ruoyi-admin/src/main/resources/application-devmy.yml`。填写本机数据库名、用户名和密码。当前数据库名为 `bishe_schema`，JDBC 地址需要包含 `allowPublicKeyRetrieval=true`。

## 4. 启动 Redis

```powershell
cd D:\develop\redis-x64-3.2.100
.\redis-server.exe
```

看到 `Ready to accept connections` 后保持窗口运行。

## 5. 启动后端

```powershell
cd D:\bishe_project\api
mvn spring-boot:run -pl ruoyi-admin
```

后端地址：`http://localhost:8087`。启动成功的判断依据是控制台出现 Tomcat 监听 8087 且没有 `Application run failed`。

## 6. 启动前端

```powershell
cd D:\bishe_project\ui
npm install --registry=https://registry.npmmirror.com
npm run dev
```

当前前端地址通常为 `http://127.0.0.1:8090/admin/`。如果端口被占用，以 Vite 控制台实际输出为准。代理配置在 `ui/vite.config.js`，当前后端目标为 `http://localhost:8087`。

## 7. 登录与验证

管理员账号为 `admin`，密码已重置为 `123456`（本地开发环境）。登录后先验证用户管理、角色管理和菜单权限，再开始实验室模块开发。

登录接口需要两个额外条件：密码必须先用 `ui/src/utils/jsencrypt.js` 里的公钥做 RSA 加密再提交；
验证码答案存放在 Redis 的 `captcha_codes:<uuid>`（当前使用 db1），调试接口时可直接读取。

## 8. 常见问题

`Public Key Retrieval is not allowed`：检查 JDBC 地址是否包含 `allowPublicKeyRetrieval=true`。

`Unable to connect to Redis`：检查 Redis 是否正在监听 6379 端口。

`vite is not recognized`：先在 `ui` 目录执行 `npm install`。

数据库连接失败：核对数据库名、用户名、密码和 MySQL 服务状态。

## 9. 开发顺序

先完成实验室和设备 CRUD，再完成预约与冲突校验，然后完成教师审核、安全考试和信用分，最后接入 Agent。每完成一个完整功能就运行接口测试，并提交一次 Git 记录。
