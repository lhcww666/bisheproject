# 若依代码生成配置（最终版）

当前采用 `module` 作为业务代码根目录。若依代码生成器是在数据库表导入后才生成 Java 和 Vue 文件，因此生成前项目中不会自动出现 `com.ruoyi.module`。

## room 配置

导入表 `room` 后填写：

```text
模块名：module
业务名：room
类名：Room
包路径：com.ruoyi.module
表注释：实验室信息表
```

后端生成目录：

```text
ruoyi-biz/src/main/java/com/ruoyi/module/room
├── controller/RoomController.java
├── domain/Room.java
├── mapper/RoomMapper.java
├── service/RoomService.java
└── service/impl/RoomServiceImpl.java
```

前端生成目录：

```text
ui/src/api/module/room.js
ui/src/views/module/room/index.vue
```
